# Business Automation

A fast, responsive, and modern landing page for **Business Automation**, configured with automated GitHub Actions CI/CD to GitHub Pages.

## Tech Stack
- HTML5 & CSS3 (Mobile-responsive, modern dark palette)
- GitHub Actions (`.github/workflows/deploy.yml`)
- GitHub Pages

## Deployment Setup
1. Push to `main` branch.
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment > Source**, choose **GitHub Actions**.
3. Every push to `main` will automatically build and publish to your GitHub Pages URL.
